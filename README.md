# Missão Aquário Digital

## Descrição

Projeto desenvolvido para a disciplina de Gestão e Qualidade de Software, com o objetivo de implementar um módulo de monitoramento da qualidade da água do aquário.

O sistema verifica os níveis de pH e temperatura, emitindo alertas quando os parâmetros estão fora dos limites ideais.

## Ambientes

- **develop:** ambiente de desenvolvimento, onde são integradas as novas funcionalidades.
- **stage:** ambiente de testes e homologação, onde as alterações são validadas antes da produção.
- **main:** ambiente de produção, contendo a versão final e validada do sistema.
